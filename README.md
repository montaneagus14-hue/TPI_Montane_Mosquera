# TPI_Montane_Mosquera

Sistema de Gestión de Países

Este proyecto consiste en el desarrollo de un sistema de gestión de datos de países utilizando Python, como parte del Trabajo Práctico Integrador de la materia **Programación I**.

El sistema permite almacenar, consultar y administrar información de distintos países mediante un menú interactivo. Para ello, utiliza un archivo CSV como fuente de datos y permite realizar diferentes operaciones sobre la información.

## Funcionalidades principales

El sistema permite:

- **Agregar países:** incorporar nuevos países verificando que existan.
- **Consultar países:** buscar y visualizar información almacenada.
- **Modificar datos:** actualizar información de los países.
- **Eliminar países:** quitar registros del sistema.
- **Listar países:** mostrar los países registrados.
- **Filtrar información:** realizar búsquedas según distintos criterios.

## Estructura del proyecto

- `main.py`: archivo principal del programa.
- `paises.csv`: archivo que contiene los datos de los países.
- `README.md`: documentación general del proyecto.

## Cómo ejecutar el programa

1. Descargar o clonar el repositorio.
2. Tener instalado Python 3.
3. Abrir una terminal en la carpeta del proyecto.
4. Ejecutar el siguiente comando:

```bash
python main.py
```

5. Seguir las instrucciones del menú interactivo.
